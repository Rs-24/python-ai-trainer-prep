# Bug Fixing Practice

This folder is dedicated to practicing debugging and refactoring.

## What this shows

- Ability to read and understand existing code
- Finding and fixing logical, off-by-one, and edge-case bugs
- Using tests to reproduce bugs and verify fixes
- Writing short explanations of what was wrong and how it was fixed

## What’s inside

- Buggy Python code and functions
- Notes or comments describing each bug

## How to run

Run the script directly with Python 3.x, for example:

```bash
python bugs.py
