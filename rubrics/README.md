# Rubrics for Evaluating Code and AI Outputs

This folder contains written rubrics and guidelines for grading coding solutions.

## What this shows

- Ability to design clear evaluation criteria
- Writing instructions that another human (or AI) could follow consistently

## What’s inside

- Markdown files with rubrics for specific coding tasks
- General scoring templates that can be reused across problems

## How to use

Open any rubric file to see the scoring system. These documents are designed to mirror the kind of evaluation work often requested in AI-training and code-assessment roles.
