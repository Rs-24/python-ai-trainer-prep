# Judging Two Solutions

This folder simulates work where you compare multiple solutions to the same coding problem and evaluate which one is better and why.

## What this shows

- Comparing different Python solutions to the same task
- Evaluating correctness, complexity, readability and use case
- Thinking like a code reviewer or AI-output evaluator

## What’s inside

- Different solutions for the same problems (e.g. efficient vs brute force)
- Written evaluations for each
