# Classic Python Coding Challenges

This folder contains solutions to classic algorithm and data-structure style problems, similar to those found on LeetCode / HackerRank / Codewars.

## What this shows

- Core problem-solving skills in Python
- Use of lists, dictionaries, sets, and strings
- Basic algorithms (searching, counting, simple sorting logic, etc.)

## What’s inside

- Implementations of common problems (e.g. palindrome checks, Two Sum, list operations)
- Comments explaining the approach and time complexity

## How to run

Use Python 3.x and run the scripts directly, e.g.

```bash
